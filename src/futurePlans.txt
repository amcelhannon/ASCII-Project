Glyph Class

Represents a single analyzed character.
Initially stores:
Java
char symbol;
double brightness;
Later expands to include bitmaps and edge data.

GlyphList Class

Represents all Glyphs generated from a single Gradient.Gradient.
Stores:
Java
ArrayList<Glyph>
Eventually becomes the primary data source for conversion.

GlyphBuilder

Converts an individual character into a Glyph.
Responsible for rendering the character and calculating brightness.
Keeps analysis logic centralized.

GlyphListBuilder

Converts a Gradient.Gradient into a GlyphList.
Uses GlyphBuilder for every character in the Gradient.Gradient.
Produces a fully analyzed character set.

Rework Gradient.Gradient Selection

When a Gradient.Gradient is selected:
Plain Text
Gradient.Gradient
↓
GlyphListBuilder
↓
GlyphList
Converter now uses Glyphs instead of raw characters.

Add Registry/Cache

Store generated GlyphLists.
Prevent rebuilding the same Gradient.Gradient repeatedly.
Supports future custom gradients efficiently.

Add Glyph Bitmaps

Extend Glyph with:
Java
bitmap[][]
Generated by GlyphBuilder.
Enables shape-based matching.

Patch Extraction and Bitmap Matching

Extract image patches matching output character size.
Compare patch bitmap against Glyph bitmaps.
Select best match using bitmap error.
Evaluate output quality here.

Add Edge Orientation to Glyph

Store edge histogram/orientation information.
Generated once when Glyphs are built.
Examples:
Java
horizontal
vertical
diagonal45
diagonal135

Add Edge Orientation to Image Patches

Analyze patches using the same algorithm used for Glyphs.
Produces directly comparable feature data.

Combine Bitmap, Brightness.Brightness, and Edge Scoring

Final matching score:
Java
score =
brightnessWeight * brightnessError +
bitmapWeight * bitmapError +
edgeWeight * edgeError;
Select Glyph with lowest score.

Expose Weights as Settings

Allow tuning:
Java
Brightness.Brightness Weight
Bitmap Weight
Edge Weight
Useful for experimenting and optimizing different gradients.
